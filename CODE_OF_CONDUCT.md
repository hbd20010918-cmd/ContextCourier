# Code of conduct

We want ContextCourier to be a useful and welcoming project for people with different
backgrounds, tools, languages, and levels of experience.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique code and claims, not people.
- Protect private data and never ask a reporter to post credentials publicly.
- Disclose copied work and respect upstream licenses.
- Use reproducible evidence when making security, performance, or compatibility claims.

## Unacceptable behavior

Harassment, discriminatory language, threats, doxxing, spam, fabricated project metrics,
coordinated abuse, and publishing another person's private information are not tolerated.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile or the most
appropriate private GitHub reporting channel. Maintainers may edit or remove content and
temporarily or permanently restrict participation when needed to protect the community.
