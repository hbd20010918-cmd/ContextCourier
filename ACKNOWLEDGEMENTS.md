# Acknowledgements

ContextCourier is an independent clean-room implementation. We studied public interfaces,
documentation, and product positioning from these open-source projects:

- [Repomix](https://github.com/yamadashy/repomix) — low-friction repository packing,
  layered excludes, and security checks.
- [Gitingest](https://github.com/coderamp-labs/gitingest) — approachable repository digest
  UX and clear summary/tree/content separation.
- [code2prompt](https://github.com/mufeedvh/code2prompt) — composable CLI and template ideas.
- [files-to-prompt](https://github.com/simonw/files-to-prompt) — a small, script-friendly
  command-line surface.
- [detect-secrets](https://github.com/Yelp/detect-secrets) and
  [Secretlint](https://github.com/secretlint/secretlint) — explainable secret-detection and
  audit workflows.
- [Reproducible Builds](https://reproducible-builds.org/) — deterministic artifact principles.

No source code, branding, README copy, or visual assets from those projects are included.
Their licenses remain with their respective authors and repositories.
