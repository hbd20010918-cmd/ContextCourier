# Codex for Open Source 申请准备

官方项目页：<https://developers.openai.com/community/codex-for-oss>

截至 2026-08-11，OpenAI 官方说明中包含：

- 六个月 ChatGPT Pro with Codex；
- 符合条件时可获得 Codex Security；
- 对把 Codex 用于 PR 审查、维护自动化、发布流程等核心开源工作的项目提供 API credits；
- 建议核心维护者或广泛使用的公开项目申请；即使不完全符合，也可以说明项目对生态的
  重要性后申请。

官方页面**没有公布“必须达到 200 Stars”这一数字门槛**。Stars 能证明真实使用和社区
关注，但不能保证获批。新仓库刚发布时，申请说服力通常有限；应该先积累可核验维护记录。

## ContextCourier 的真实申请证据清单

- [ ] 公开 GitHub 仓库和 OSI 许可证。
- [ ] 可安装、带自动化测试的正式 Release。
- [ ] 清楚解释它解决的开源维护问题，而不是为了订阅临时拼出的演示。
- [ ] 持续维护 Issue、PR、Release 和安全报告。
- [ ] 真实用户反馈、下游使用或贡献者记录。
- [ ] 说明 Codex 如何用于测试、PR 审查、发布或日常维护。
- [ ] 所有使用量、Stars、下载量和贡献者数字都附 GitHub/PyPI 等可核验来源。

## 建议申请时机

不要伪造 Stars、下载量、Issue 或贡献者。先发布 v0.1，收集真实反馈，修复早期问题并
发布至少一个维护版本。只要项目出现真实使用价值，就可以按官方页面的“即使不完全符合
也可说明原因后申请”提交；是否通过由 OpenAI 审核决定。
