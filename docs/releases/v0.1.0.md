# ContextCourier v0.1.0 — first public release

ContextCourier is a local-first CLI for carrying verifiable, secret-aware project context
across AI coding tools and accounts.

Requires Python 3.11+. Git is recommended for exact repository and ignore semantics, but
ordinary directories can be scanned through a clearly labelled best-effort fallback.

## Highlights

- `ctxcourier scan` previews selected, skipped, and redacted content.
- `ctxcourier pack` creates a deterministic `.contextcourier.zip` with no network call.
- Known credential containers are excluded and high-confidence text secrets are redacted.
- `--fail-on-secret` provides a write-nothing policy mode for sensitive projects and CI.
- `ctxcourier verify` checks paths, entry sets, sizes, and per-entry SHA-256 before import.
- Every pack contains human context plus Codex/AGENTS, Claude, Cursor, and universal adapters.
- English and Simplified Chinese guides cover honest account-switching boundaries.

## Install

```bash
python -m pip install "git+https://github.com/hbd20010918-cmd/ContextCourier.git@v0.1.0"
```

Or download the wheel/sdist and `SHA256SUMS.txt` attached to this release, then compare the
artifact's SHA-256 before installation.

## Important boundary

ContextCourier transfers project knowledge, not ownership of server-side chat history,
subscriptions, login sessions, or private account tasks. Secret detection is heuristic;
review a pack before sharing it.
