# Support

- Usage questions and reproducible bugs: open a GitHub Issue using the appropriate template.
- Feature ideas: open a feature request and explain the handoff problem before proposing an
  implementation.
- Security-sensitive reports: use the private process in [SECURITY.md](SECURITY.md).
- Account billing, ChatGPT subscriptions, and missing server-side tasks are product-provider
  issues; ContextCourier cannot access or change them.

This is a volunteer-maintained open-source project. Response times are best effort.
